Политика конфиденциальности игры «Путь: лабиринты»

Дата редакции: 1 октября 2026 года.

Локальный прогресс

Приложение хранит на устройстве текущие лабиринты, количество ходов, прохождения, лучшие результаты и даты выполненных задач дня. Регистрация не нужна. Прогресс не отправляется разработчику и не синхронизируется с сервером.

Резервная копия

Пользователь может сам выбрать файл для экспорта JSON-копии и файл для её восстановления. Приложение читает выбранный файл только для импорта. Импорт заменяет текущий прогресс после отдельного подтверждения. Копия не передаётся разработчику; сохранность файла в выбранном хранилище зависит от пользователя и поставщика этого хранилища.

Сеть, реклама и аналитика

В версии 1.0.0 нет сетевого разрешения, рекламного SDK, аналитики, покупок и сбора рекламного идентификатора. Ссылка на эту политику открывается во внешнем браузере по действию пользователя. Перед выпуском версии с сетевыми сервисами или рекламой политика будет обновлена.

Удаление данных

Удаление данных приложения в настройках Android или удаление игры стирает локальный прогресс. Экспортированные пользователем файлы остаются там, куда он их сохранил.

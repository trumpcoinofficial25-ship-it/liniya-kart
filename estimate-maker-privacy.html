Политика конфиденциальности — «Смета по делу»

Дата: 2 октября 2026 года. Приложение store.tastyplay.estimate работает без регистрации и без разрешения на доступ к интернету. Оно не показывает рекламу, не содержит покупок и не использует аналитику. Разработчик не получает введённые данные.

Названия смет, примечания, разделы, работы, материалы, количество и цены сохраняются локально на устройстве. Приложение использует их для расчёта итогов и подготовки PDF. Цены вводит пользователь; приложение не получает их от поставщиков. При удалении приложения локальные данные могут быть удалены операционной системой.

Пользователь может вручную сохранить JSON-копию, восстановить данные из выбранного файла, сохранить PDF или открыть системное меню отправки PDF. Файлы сохраняются в выбранном пользователем месте. При отправке PDF данные получает только приложение или адресат, которого выберет пользователь; дальнейшая обработка определяется выбранным сервисом. Приложение само не загружает файлы на сервер разработчика.

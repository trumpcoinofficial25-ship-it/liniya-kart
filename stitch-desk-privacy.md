# Политика конфиденциальности — «Вышивка рядом: схемы и PDF»

Дата: 7 октября 2026 года. Android-пакет: store.tastyplay.stitchdesk.

Разработчик: Татьяна Зайцева. Для вопросов: tatyanazaiceva76@yandex.com.

## Что хранится

Приложение хранит на устройстве созданные пользователем схемы: название, сетку полных крестиков, цвета, названия и коды ниток, заметки, каунт, отметки прогресса и личные палитры. Для преобразования в схему пользователь сам выбирает изображение через системный выбор файлов Android. Изображение читается для расчёта сетки; исходное фото и его EXIF-метаданные не сохраняются в книге. Сохраняются только полученные клетки и палитра. Другие фото, контакты и файлы не читаются.

## Сеть и внешние сервисы

В приложении нет аккаунта, сетевых запросов, аналитики, рекламы, платёжных SDK и встроенных покупок. Приложение не передаёт схемы и фото разработчику. Камера, микрофон, геолокация, рекламный идентификатор и общий доступ к хранилищу не запрашиваются.

Пользователь может выбрать файл из облачного провайдера через Android; его загрузка и правила обработки определяются этим провайдером. Само приложение работает с выбранным файлом. Интернет не нужен для локальных схем и файлов на устройстве.

## Экспорт и перенос

По команде пользователя создаются PDF, PNG, CSV и копия книги .stitchbook. В копии есть схемы, палитры, заметки, отметки прогресса и тема; это обычный JSON без пароля и шифрования. Не помещайте туда сведения, которые не хотите раскрывать. Для сохранения пользователь сам выбирает папку или провайдера Android; для передачи — приложение и получателя через системное меню. Дальнейшая обработка выбранным сервисом определяется его правилами. Передача не происходит автоматически.

Импорт читает только выбранную копию или палитру CSV. Перед добавлением показывается состав. Добавляются независимые копии; текущие схемы и тема не заменяются.

## Управление данными

Схемы, личные палитры и выходные файлы можно удалить в интерфейсе. Изменения и отметки сохраняются в локальной книге. Последние действия можно отменить до закрытия схемы; долговременная история отмены не хранится. Не более 60 выходных файлов и 100 МиБ: старые выходные файлы убираются при превышении лимитов, сама книга от этого не удаляется. Необходимые копии сохраняйте отдельно.

Автоматическое резервное копирование Android для приложения отключено. Удаление приложения или очистка его данных удалит локальную книгу. Файлы, сохранённые пользователем вне приложения, удаляются отдельно средствами выбранного хранилища. При повреждении книга не заменяется автоматически; можно сохранить исходный файл для восстановления в пределах 30 МиБ.

## Поддержка

Если пользователь сам напишет на почту поддержки, разработчик получает текст и вложения этого письма и использует их для ответа. Не отправляйте лишние личные данные. При изменении обработки данных политика будет обновлена.

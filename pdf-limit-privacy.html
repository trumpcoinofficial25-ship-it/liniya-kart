Политика конфиденциальности — PDF до лимита

Дата редакции: 1 октября 2026 года.

«PDF до лимита» — приложение для Android, которое создаёт уменьшенную копию выбранного PDF на устройстве.

Какие данные обрабатываются

Приложение не собирает и не отправляет разработчику персональные данные или содержимое документов. В приложении нет регистрации, аналитики, рекламных SDK и сетевых разрешений.

Когда пользователь выбирает документ, Android предоставляет приложению доступ к этому файлу через системное окно выбора документов. Приложение читает только выбранный PDF, обрабатывает его локально и записывает новую копию в место, которое указывает пользователь. Исходный документ не перезаписывается.

Для обработки приложение создаёт временный файл в собственном кэше. Он удаляется при выборе другого документа или следующем сжатии; Android может очистить кэш в любое время. Пользователь также может очистить данные приложения или удалить приложение в настройках Android.

При выборе действия «Поделиться» Android передаёт выбранную копию приложению, которое пользователь сам выбирает в системном меню. Дальнейшую обработку регулируют правила этого приложения.

Политика конфиденциальности приложения «Автодневник»

Дата редакции: 1 октября 2026 года.

Какие данные хранятся

Названия автомобилей, пробег, даты и суммы расходов, объём топлива, заметки и планы обслуживания сохраняются только в локальном хранилище приложения на устройстве пользователя. Приложение не требует регистрации и не отправляет эти данные разработчику или на сервер.

Резервная копия

Пользователь может сам выбрать файл для экспорта JSON-копии и затем импортировать его. Содержимое выбранного файла читается только для восстановления данных. Приложение не передаёт копию разработчику. За сохранность файла в выбранном хранилище отвечает пользователь и поставщик этого хранилища. Импорт заменяет текущие локальные записи только после подтверждения.

Сеть и реклама

В версии 1.0.0 нет рекламного SDK, аналитики, сетевого разрешения и покупок. Приложение не собирает рекламный идентификатор. Ссылка на эту политику открывается во внешнем браузере по действию пользователя. Перед выпуском версии с сетевыми сервисами или рекламой эта политика будет обновлена.

Удаление данных

Записи и планы можно удалять в приложении. Удаление данных приложения в настройках Android или его удаление стирает локальные записи; экспортированные пользователем файлы при этом остаются там, куда он их сохранил.

Версия 1.1.0 и необязательная покупка PRO

Бесплатные функции «Автодневник» сохраняются. Версия 1.1.0 дополнительно позволяет купить PRO за 299 ₽ один раз через Lava. Подписки нет.

Интернет используется при явном начале покупки, проверке оплаты и восстановлении доступа. Для этих действий обрабатываются электронная почта, выбранное приложение, сумма и статус заказа, случайный ID установки и хэш секретного ключа покупки. Почта и сведения заказа передаются Lava. Банковские реквизиты вводятся на странице Lava; приложение и сервер продавца их не получают.

Записи приложения и экспортируемые файлы остаются на устройстве; сервер покупки их не получает. Перед началом оплаты пользователь отдельно подтверждает согласие. Отказ от покупки и согласия не ограничивает бесплатные функции.

Подробности: данные покупки, отдельное согласие, условия покупки PRO.
